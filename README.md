# Valley Network - Odoo App

A free Odoo app that adds a Valley page to your Odoo instance, allowing users to join Valley directly.

## Installation

1. Clone this repository into your Odoo addons directory
2. Update your app list in Odoo
3. Install "Valley Network" from the Apps menu

## What it does

- Adds a "Valley" menu to your Odoo instance
- Opens a branded Valley page with information about the platform
- "Join Valley" button redirects to Valley's onboarding

## Requirements

- Odoo 19.0
- Dependencies: `base`, `web`
